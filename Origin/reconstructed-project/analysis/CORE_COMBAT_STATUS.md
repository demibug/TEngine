## 3. 仍需还原的核心战斗模块

### P0：必须完成

#### 3.1 武将完整战斗组件

当前已具备配置和合成，但仍缺：

- 武将正式攻击循环。
- 武将目标选择和攻击范围计算。
- 武器装备后对攻击力、攻速和攻击效果的影响。
- 武将经验、升级和战斗属性刷新。
- 武将技能挂载、触发和攻击前后钩子。
- 武将死亡、部件归属解除、回收和重新合成。

当前 `GeneralUnit` 仍主要是纯状态承载对象，不能视为完整 `GeneralBase` 战斗还原。

#### 3.2 武器实际攻击分支

- 44 个武器入口已注册，但大量普通武器仍共用 `src/weapons/types/Weapon.js` 的占位攻击。
- 需要恢复每个武器的攻击目标、伤害、攻速、范围和触发概率。
- 需要恢复武器与投射物、Buff、近战攻击效果之间的连接。
- 需要恢复已确认的特殊武器分支，例如七星刀、铁弓、霸王弓、诸葛连弩等。

#### 3.3 武将主动技能

以下技能当前仍通过延迟契约返回，尚未形成真实效果：

- 跳斩
- 七进七出
- 战吼
- 圣剑
- 箭雨
- 火箭齐射

`StunPassive` 和多数 Boss 技能已有处理入口，但仍需核对原始数值和边界行为。

#### 3.4 枪兵、骑兵的正式攻击时序

基础贯穿和范围伤害对象已经存在，但还需要恢复：

- 原始动画事件到命中的准确时刻。
- 统一攻击效果管理器。
- 攻击对象池和回收顺序。
- 多目标命中去重、死亡目标重选和清理时机。

当前枪兵、骑兵仍保留直接推进效果对象的兼容路径，不能视为最终原始时序。
