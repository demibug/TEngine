# BowSoldier 目标选择

## CONFIRMED

1. 弓兵使用既有 `EnemyManager.queryTargets()`，搜索半径来自正式弓兵范围 `3.5 × 80 = 280px`。
2. EnemyManager 继续执行 80px 空间格扫描、阵营过滤、死亡过滤、可攻击状态过滤以及圆形攻击区与 80×80 敌人 AABB 相交检测。
3. `ok.ox` 不选择几何最近目标，而是在候选中选择 `Bm` 最小者。`Bm` 是敌人到路径终点的剩余距离语义，因此重建名称为 `remainingPathDistance`。
4. 攻击状态开始时选一次目标；收到动画 STOPPED 时再次通过敌人 ID 验证。原目标失效时再从当前候选中选 `Bm` 最小的可攻击目标。
5. 箭矢生成后，即使目标离开弓兵的 280px 攻击范围，移动策略仍按 ID 追踪目标当前位置；不会因为离开攻击范围自动取消。
6. 多个弓兵和其他友军可以选择同一敌人。`PlacementReservationRegistry` 不参与攻击占位。

## 未采用的规则

- 不按当前生命值排序。
- 不按几何距离优先。
- 不优先 Boss。
- 不预测目标速度，也不做提前量射击。
- 不对 EnemyManager 返回集合做额外全局排序。
