# Mob0 对象池复位契约

## 构造一次

方向向量、击退向量、路径点对象、贡献者数组和足迹数组在逻辑实体构造时创建并复用。

## 每次出生必须复位

- 新 ID、阵营、特殊标记
- `targetable/deathStarted/inPool`
- 生命、速度和动画
- 路径引用及索引
- 攻击冷却、接触回调标记
- 位置、网格、剩余路径距离
- 击退、移动锁、停止移动
- 伤害贡献者和表现计数

## 回收顺序

1. `onDestroy`。
2. EnemyManager 和空间索引注销。
3. `Laya.timer.clearAll(enemy)`。
4. 清路径、状态、生命条、击退、贡献者和监听。
5. 逻辑实体进入类池。
6. 动画表现复位并回收。
7. `mob` 根节点进入字符串键池。

## 已验证不泄漏

测试证明旧目标/路径、生命值、死亡状态、攻击冷却、监听、空间索引、EnemyManager 注册和定时器均不会进入下一生命周期。通过生命周期代号和 `clearAll`，旧的 50ms 接触回调也不能影响复用后的对象。
