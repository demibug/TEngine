# Mob0 目标选择

## 结论

Mob0 本身没有“寻找并攻击普通单位”的分支。它只沿所属侧的固定 A* 路径推进，在倒数第二次路径索引转换时触发 aDou 接触攻击。

`EnemyManager.qx` 的空间查询方向相反：它为士兵和武将选择可攻击的敌人。过滤规则为：

1. 状态不能为 0 或 4。
2. `enemy.nm === unit.side`。这表示单位攻击自己战区内的来敌。
3. `rm/targetable` 必须为真。
4. 圆形攻击范围与 80×80 敌人矩形相交。
5. 返回顺序来自格子扫描和 Set 插入顺序，不额外排序。

无普通单位目标时，Mob0 不执行回退目标选择；它继续沿路径接触本侧 aDou。`PlacementReservationRegistry` 不参与 Mob0 的目标选择。
