# 友军对象池复位契约

## 必须复位

- 运行时 ID、文字键、阵营、容器和前后格位。
- 等级、经验、等级显示。
- 攻击力、范围、间隔及所有临时修正。
- 当前目标数组、上次攻击时间和攻击状态。
- 激活、禁用、拖拽、放置 Tween 和生命周期代号。
- 定时器、事件监听、GameLoop 注册。
- 表现节点的位置、缩放、旋转、透明度、过滤器和非等级子节点。
- 动画监听、播放状态和倍率。

## 不得残留

复用测试确认：旧目标、旧阵营、旧等级、旧攻击加成、旧冷却、旧延迟攻击、旧格位、重复注册和重复回收均不会进入新生命周期。

## 两层池

```text
逻辑池：ObjectPool.takeByClass / recoverByClass(KnifeSoldier)
表现池：ObjectPool.takeByKey / recoverByKey("soldier")
```

两层池独立计数，不通过销毁节点模拟回收。
