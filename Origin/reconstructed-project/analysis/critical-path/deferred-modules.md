# 第三轮暂缓模块

| 模块 | 原始范围/符号 | 本轮保留契约 | 暂缓内容 | 影响 |
|---|---|---|---|---|
| 微信/字节平台实现 | qN、qB、r2 | initialize、preload、login、channelAppId、direct-match、startGame | 授权、广告、分享、开放数据域、录屏等 | 开发模式可运行；正式平台尚不可用 |
| NET-01 正式服务 | qK | 第二轮实现保持不变 | 本轮不调用真实服务器 | 无行为回归 |
| 完整 PlayerData | tY/tw | 体力、场次、地图、日胜负、最小排行/道具契约 | 云存档、武器碎片、经济外循环等 | 不阻止进入战斗 |
| aDou 骨骼包装类 | uz、tm | 对象池键、资源路径、fast-mode、节点属性 | Spine 播放、受击、生命、目标控制组件 | 阻止真实视觉与胜负伤害链 |
| 敌人基类与移动 | ro、pe | Mob0 创建、注册、入口坐标、更新契约 | 寻路、碰撞、攻击、死亡、掉落 | 首帧/生成可测，实际战斗不可完成 |
| 友军/武将创建 | vc 及工厂 | 空注册表与清理 | 招兵、拖拽、合成、武器、攻击 | 原始启动本就不自动创建；后续最优先 |
| Buff/技能/特效 | vd、qs 等 | 生命周期可观测适配器 | 实际触发器、数值、视觉 | 不阻止启动；阻止完整战斗表现 |
| AI/匹配对手 | vS 等 | start/init/gameOver 调用契约 | 出兵策略、放置、难度 | 不阻止场景进入 |
| PauseDialog/GameOverScene | 多个 UI 类 | 暂停入口与 game-over 事件 | UI 节点、动画、结算页 | 清理可测，真实 UI 不可渲染 |
| Scene `.ls` | 缺失 | 开发场景工厂提供最小节点 | 真实节点层级、序列化属性、资源绑定 | 主要真实画面阻塞项 |

开发适配器遇到未恢复调用会明确抛错，不使用 Proxy 或空对象吞掉异常。
