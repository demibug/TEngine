# 首个正式友军兵种选择

## 选择结果

- 原始符号：`tb.zx[0]` 中的匿名类
- 重建名称：`KnifeSoldier`
- 正式文字键：`刀`
- 工厂索引：`0`
- 表现键：`knife`
- 命名可信度：`HIGH`

## 选择依据

刀兵直接继承 `td`，攻击方法 `Nx` 使用现有 `EnemyManager.qx` 查询目标，构造攻击效果描述后最终进入 `target.hit(damage, attacker)`。其最小依赖闭包仅需要友军基础层、空间查询、延迟攻击时间线和已恢复的敌人伤害接口，能够形成真实击杀闭环。

## 未选择 `ok` 的原因

`ok` 已确认是正式弓兵：`Q_ = "bow"`，并配置弓箭图片资源。其攻击立即依赖目标抛物线角度、箭矢/投射物配置、命中策略、Tween 旋转、攻击效果管理器和资源表现。用即时伤害替代这些逻辑会改变行为，因此本轮暂缓。

枪兵和骑兵位于同一基础构造表，但分别依赖贯穿和范围攻击闭包，依赖规模也大于刀兵。没有创建原游戏不存在的通用 `BasicSoldier`。
