# FairyGUI Editor 组件扩展第三参数语义

## 问题现象

项目插件调用 `RegisterComExtension(name, className, "FairyGUI.GComponent")` 时加载失败，Editor 报错 `Component extension 'FairyGUI.GComponent' does not exist!`。

## 文档位置

`.codex/skills/tengine-dev` 未记录 FairyGUI Editor 项目插件 API；项目调研文档 `docs/HotFix架构/FairyGUI模块接入调研.md` 曾将 `superClassName` 推断为 FairyGUI 原生类型名。

## 正确 API

当前 Editor 的签名为 `RegisterComExtension(name, className, superClassName)`。第三参数表示上一级已注册自定义扩展的 `className`，不是 FairyGUI 原生 C# 类型。直接基于默认 `GComponent` 的首级自定义扩展应传 `nil`。

```lua
App.project:RegisterComExtension('Window', 'GameFUI.FUIWindow', nil)
App.project:RegisterComExtension('Widget', 'GameFUI.FUIWidget', nil)
```

## 建议修正

涉及 FairyGUI Editor 组件扩展时，应先根据 Editor 运行时错误或真实插件验证第三参数语义。只有自定义扩展继续继承另一个已注册自定义扩展时，第三参数才传父扩展的完整 `className`。
