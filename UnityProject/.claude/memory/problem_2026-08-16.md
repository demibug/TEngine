# Luban helper 新建表注册缺少项目必需列

- 问题现象：`luban_helper.py table add` 创建 `battle.TbWavePlan` 后，`__tables__.xlsx` 的 `read_schema_from_file` 与 `group` 留空；helper 自身 `validate --all` 仍将该表判为有效。
- 文档位置：`.agents/skills/luban-dev/references/operating-guide.md` 的 `table add` 章节；该章节说明会正式注册新表，但未说明项目内 `read_schema_from_file` 的要求。
- 源码验证后的正确配置：表结构定义在 `wave_plan.xlsx` 时，注册行应设置 `read_schema_from_file=True`；客户端表应设置 `group=c`。
- 建议修正：扩展 helper 的 `table add/update` 参数与校验，支持并校验 `read_schema_from_file`、注册行 `group`，避免只校验数据表自身表头。
