# FairyGUI package cleanup ordering in Unity Editor

## Symptom

Stopping Play Mode after a successful FairyGUI window open logged that the managed package id/name was invalid while
`FguiPackageService` tried to remove it.

## Cause

Official FairyGUI v5.2.0 calls `UIPackage.RemoveAllPackages()` from `StageEngine.OnApplicationQuit()`. Unity invokes
that before TEngine's destroy listener releases `FguiWindow` and its package lease, so the SDK registry can already be
empty even though the adapter still owns YooAsset leases.

## Resolution

`FguiPackageService.RemovePackageIfPresent` now checks that the registered package is the same instance before calling
`UIPackage.RemovePackage`. A missing/replaced registry entry is treated as already removed; asset and dependency leases
are still disposed by the normal adapter cleanup. The regression test
`SdkGlobalCleanup_BeforeLeaseRelease_IsIdempotent` models the SDK-first shutdown order.

## Real window tests require Play Mode

The earlier EditMode isolation advice above has been superseded: replacing only the host does not isolate actual
`UIPackage.CreateObject` construction. The published Main component contains text; `FontManager.GetFont` can return a
cached `DynamicFont` whose native Unity Font was destroyed during Editor lifecycle transitions. The observed failure
was `DynamicFont.GetLineHeight -> Font.fontSize`, before the window's creation hook. The stack does not identify the
operation that destroyed the font.

`WindowModule_MergesConcurrentShow_AndClosePreventsLateWindow` now belongs to `FguiWindowModuleTests` in the PlayMode
assembly. It uses `FguiModule.Instance`, the default real runtime host, and releases the singleton in `finally`.
Entering Play Mode runs the SDK's SubsystemRegistration font-cache initialization. The test asserts real package
text construction and allows the Stage to update, alongside the existing concurrency and cleanup assertions. It no
longer uses a fake host or suppresses the singleton construction guard. The published assets still come from a test
AssetDatabase provider; actual YooAsset bundle/Player verification remains separate.
