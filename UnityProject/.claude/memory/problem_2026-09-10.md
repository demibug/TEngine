## 典型问题清单

### 1. 虚构 API / 虚构类
- **问题现象**：多篇文档示例使用 `GameEventDef.OnGoldChanged`、`IGameEvent_Event.OnGoldChanged`（作为现成类）、`IGoldEvent_Event`、`IItemEvent` 等，工程中不存在。
- **正确 API**：工程唯一 `[EventInterface]` 接口为 `ILoginUI`（`Assets/GameScripts/HotFix/GameLogic/IEvent/ILoginUI.cs:5`），Source Generator（`Tools/GameEventSourceGenerator/`，以 `Assets/TEngine/Runtime/Core/GameEvent/SourceGenerator.dll` RoslynAnalyzer 形式交付）生成 `{接口名}_Event`，成员为 `public static readonly int <方法名>`（非 const，`EventInterfaceGenerator.cs:255`）。
- **建议修正**：已将各文档示例锚定到 `ILoginUI` 并加"示意接口"标注。

### 2. LoadAssetAsync 取消语义写反
- **问题现象**：resource-patterns.md 旧文写 `catch (OperationCanceledException)` 处理取消。
- **正确 API**：取消时 `LoadAssetAsync` **返回 null，不抛异常**（`ResourceModule.cs:1502-1541`；仅池关闭极端情况抛 OCE）。
- **建议修正**：已改为 null 检查，并上浮至 SKILL.md 核心红线 7。

### 3. `await downloader` 合法性误判（复核阶段假阳性）
- **问题现象**：复核 agent 曾断言"下载器无 GetAwaiter 扩展，直接 await 无法编译"，并把文档改成轮询。
- **正确 API**：UniTask 包自带扩展 `Packages/UniTask/Runtime/External/YooAsset/AsyncOperationBaseExtensions.cs:10`（versionDefines 定义 `UNITASK_YOOASSET_SUPPORT` 自动启用），`await downloader` 合法且是 `ProcedureDownloadFile.cs:86` 的真实写法；区别仅在 Failed 时 await 会抛异常，轮询（`ProcedureTwoStageUpdate.cs:545`）可自行检查状态。
- **建议修正**：resource-patterns.md 已恢复两种写法并注明差异。

### 4. 程序集依赖描述不全
- **问题现象**：architecture.md / hotfix-workflow.md 称"GameUpdater 仅依赖 TEngine.Runtime"。
- **正确事实**：`GameUpdater.asmdef` 引用 TEngine.Runtime（GUID 24c092ae…）+ UniTask（GUID f51ebe6a…）。
- **建议修正**：两文档已补。

### 5. 代码生成器双模式口径不一
- **问题现象**：旧文档把剪贴板模式（ScriptGenerator.cs，FindChild 绑定）与文件模式（ScriptAutoGenerator.cs，UIBindComponent 索引绑定）混为一谈；naming-rules 称 BindComponent 模式 `m_btnClose`→`m_Close`（错误，不剥类型段）；`GameLogic/UIBindComponent/` 路径错误（实为 `GameLogic/Module/UIModule/UIBindComponent/`）。
- **正确事实**：同一 partial 类两组菜单，由 `ScriptGeneratorSetting.asset` 的 `useBindComponent` 互斥启停（当前 =1，即 BindComponent 模式）；当前 CodeStyle=MPrefix，字段名=前缀+去 m_ 前缀（`m_btnClose`→`m_btnClose`）。
- **建议修正**：ui-patterns.md / naming-rules.md 已统一口径。

### 6. Luban 构建源与行结构
- **问题现象**：文档写"克隆 luban-next"；Excel 行结构描述为"第2行##type"。

- **建议修正**：luban-config.md 已改。

### 7. MCP 文档环境口径
- **问题现象**：mcp-tools/mcp-visual 未说明 MCP 可用性；`Packages/MCPForUnity`（com.coplaydev.unity-mcp v9.7.3）本地包源码存在但 manifest.json 未引用。
