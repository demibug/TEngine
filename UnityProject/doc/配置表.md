# TEngine 配置表与美术资源规范

> 基于 `Configs/GameConfig/Datas/` 实际 xlsx、非生成业务代码引用与 `GameProto/GameConfig/` 生成 C# 类核验。字段名以生成 C# 类为准。最后核验：2026-08-24。本次删除 67 个无代码消费的非主键字段；无人消费的表仅保留 Luban 必需的 `Id` 主键。

## 配置表逐表说明

### unit.xlsx — 小兵基础配置

用途：定义 4 种基础兵种（刀/弓/枪/骑）的战斗属性与动画绑定，是兵种战斗逻辑的权威来源。

| 字段 | 类型 | 意义 |
|------|------|------|
| Id | int | 主键，兵种唯一 ID |
| Text | string | 显示名 |
| AnimationKey | string | 动画键，关联 soldier_visual 表取得锚点偏移（knife/bow/pike/cavalry） |
| RangeCells | float | 攻击范围，以格为单位 |
| AttackDamage | int | 基础攻击力 |
| AttackIntervalSeconds | float | 攻击间隔，秒 |
| DamageMode | string | 伤害模式：近战/单体/近战枪击/范围 |
| TargetPolicy | string | 选敌策略：nearest（最近）/ closest_end（离终点最近） |

---

### unit_level.xlsx — 小兵等级倍数

用途：定义每个等级的伤害与攻速倍率。每行对应一个等级，运行时按等级 ID 查询。

| 字段 | 类型 | 意义 |
|------|------|------|
| Id | int | 等级 ID（主键），从 1 开始 |
| DamageLevelMultipliers | float | 该等级的伤害倍率，乘到基础攻击力上 |
| AttackSpeedLevelMultipliers | float | 该等级的攻速倍率，乘到基础攻速上 |

### enemy.xlsx — 敌人目录

用途：登记所有敌人类型，绑定 Prefab 资源地址，区分普通敌人与技能召唤类。

| 字段 | 类型 | 意义 |
|------|------|------|
| Id | int | 主键，敌人唯一 ID |
| TypeIndex | int? | 普通敌人类型索引，必须唯一；留空表示技能召唤类，不进入普通波次目录 |
| ResourceAddress | string? | YooAsset Prefab 地址，如 Mob0，必须与 Prefab 文件名一致 |

### enemystats.xlsx — 敌人运行时数值

用途：定义敌人的实际战斗数值。Id 与 enemy 表的 Id 一一对应，普通敌人在此表必须有数据行。

| 字段 | 类型 | 意义 |

| MoveSpeed | int | 移动速度，逻辑像素/秒 |

| EarlyRoundHealthMultipliers | List&lt;float&gt; | 前期波次额外血量倍率 |
| ContactDamage | int | 抵达终点时对目标造成的伤害 |
| RewardGold | int | 击杀奖励金币 |

| Grid | List&lt;List&lt;string&gt;&gt; | 列优先 grid[x][y]，每格编码 kind_lane：kind（0道路/1可放置/2阻挡）、lane（0对手方/1玩家方） |

### wave_plan.xlsx — 逐波计划表

用途：定义当前启用计划下每一波的具体内容（敌人/Boss/数量/延迟/生成侧），是有限关卡的正式波次配置。同一计划 Id 下 Order 连续递增。

| 字段 | 类型 | 意义 |
|------|------|------|
| Id | int | 计划 ID，应与 wave.activePlanId 一致 |
| Order | int | 波次顺序，从 1 开始连续递增，不可重复、不可跳号 |
| Kind | EWaveKind | 波次类型：Normal=普通波 / Boss=Boss 波 |
| EnemyId | int? | Normal 波的敌人 ID，留空时使用地图的 EnemyId |
| NormalCount | int | Normal 波怪物数量，Boss 波填 0 |
| DifficultyIndex | int | 难度索引，索引 enemystats.healthByWave，从 0 开始 |
| BossId | int? | Boss 波必填的 Boss ID，Normal 波留空 |
| PreDelayMs | long | 本波开始前的等待时间，毫秒 |
| SpawnIntervalMs | long | 普通怪之间的出生间隔，毫秒 |
| PostDelayMs | long | 本波结束后的等待时间，毫秒 |
| PlayerLane | bool | 玩家侧是否生成 |
| OpponentLane | bool | 对手侧是否生成，至少一侧必须为 true |
| StrategyProfile | int | 生成策略索引，引用 wave.spawnStrategies 的行，从 0 开始 |

## 美术资源制作规范

### 资源根目录

```
Assets/
├── AssetRaw/                    ← YooAsset 资源根（DefaultPackage）
│   ├── Battle/                  ← 战斗资源（自定义地址规则）
│   │   ├── Prefabs/
│   │   │   ├── Enemies/         ← 普通敌人 Mob0~3 + Boss Spine 簇
│   │   │   ├── Generals/        ← 武将 Spine 簇
│   │   │   ├── Soldiers/        ← 兵种 Prefab
│   │   │   ├── Projectiles/     ← 投射物
│   │   │   ├── Targets/         ← 保护目标
│   │   │   └── World/           ← 地图 Prefab
│   │   ├── Sprites/             ← 战斗精灵/贴图
│   │   └── Source/Laya/         ← Laya 源图集（被排除，不打包）
│   └── Configs/                 ← Luban bytes（PRELOAD）
├── SourceAssets/                ← 源美术资源
│   └── SpineConversion/         ← Spine 原始导入
│       ├── Boss/{Name}/{sub}/
│       └── Generals/{Name}/
└── Editor/AssetBundleCollector/ ← YooAsset 收集器配置
```

### YooAsset 地址规则

全局：`EnableAddressable=true`、`LocationToLower=false`（地址区分大小写）。

Battle Group 自定义规则（`BattleAssetAddressRule.cs`）：

| 资源类型 | 地址计算 | 示例 |
|---------|---------|------|
| Prefab | 文件名去扩展名 | `Mob0.prefab` → `Mob0` |
| Spine 源文件（.json/.atlas.txt/.png） | 相对 CollectPath 的完整路径（保留扩展名） | `zhangfei.json` → `Prefabs/Generals/ZhangFei/zhangfei.json` |
| 普通贴图 | 相对 CollectPath 去扩展名路径 | `generalParts_0.png` → `Sprites/.../generalParts_0` |

Spine 源目录必须在 `BattleAssetAddressRule.SpineSourceDirectories` 注册，否则同名 .json/.png 地址冲突。`Battle/Source/Laya/` 被 Filter 排除，不打包。

### Prefab 命名规范

| 类别 | 命名模式 | 示例 | 配置表字段 |
|------|---------|------|-----------|
| 普通敌人 | `Mob{N}` | Mob0 | enemy.resourceAddress |
| Boss | `{拼音名}` | ZhangLiang | boss.resourcePath |
| 武将 | `{拼音名}` | ZhangFei | general.prefabAddress |
| 兵种 | `{WeaponType}Soldier` | SpearSoldier | （代码引用） |
| 投射物 | `{Name}` | Arrow | projectile.primaryType |
| 地图 | `BattleMap{N}` | BattleMap0 | map.resourceAddress |

Prefab 文件名即地址，跨目录不能重名；地址区分大小写，配置表填写须与文件名一致。

### Spine 资源规范

源文件导入（SourceAssets）：统一命名 `skeleton.json` / `skeleton.atlas.txt` / `skeleton.png`。

运行时资产（AssetRaw），每个 Spine 角色含 7 个文件，以角色拼音小写为前缀：

| 文件 | 命名 |
|------|------|
| Prefab | `{Name}.prefab`（首字母大写） |
| 骨骼数据 | `{name}.json`（全小写） |
| 图集描述 | `{name}.atlas.txt` |
| 贴图 | `{name}.png` |
| Atlas 资产 | `{name}_Atlas.asset` |
| 材质 | `{name}_Material.mat` |
| SkeletonData | `{name}_SkeletonData.asset` |

动画名配置：配置表中 `boss.attackAnimation`/`idleAnimation`/`followupAnimation`、`general.animationKey` 必须与 SkeletonData 中的动画名完全一致（区分大小写）。

### 贴图规范

武将字形贴图（generalParts）：路径 `Battle/Sprites/Extracted/GameObject/soldier/generalParts_{index}.png`。武将 `partWords` 每个字经 `GeneralPartGlyphMap` 映射到索引：

| 索引 | 字 | 索引 | 字 | 索引 | 字 | 索引 | 字 |
|------|----|------|----|------|----|------|----|
| 0 | 赵 | 5 | 超 | 10 | 黄 | 15 | 祖 |
| 1 | 云 | 6 | 关 | 11 | 忠 | 16 | 甄 |
| 2 | 张 | 7 | 羽 | 12 | 苞 | 17 | 宓 |
| 3 | 飞 | 8 | 平 | 13 | 翼 | 18 | 刘 |
| 4 | 马 | 9 | 兴 | 14 | 盖 | 19 | 备 |

其他贴图：数字位图字体 `bitmapFont/number{1-8}.png`、关卡徽章 `LevelBadge/level_number_{1-8}.png`、敌人散件 `GameObject/enemy/`、兵种序列帧 `soldier/anim/soldier_{0-3}/`、地图背景 `Map/mapBg/mapBg{N}/`。

### 配置表字段 → 资源映射

## 美术制作 Checklist

### 新增普通敌人（Mob{N}）

1. 创建 `Assets/AssetRaw/Battle/Prefabs/Enemies/Mob{N}.prefab`（文件名即地址）
2. `enemy.xlsx` 新增行：Id / TypeIndex（唯一）/ ResourceAddress = `Mob{N}`
3. `enemystats.xlsx` 新增同 Id 数值行
4. 散件精灵放入 `Battle/Sprites/Extracted/GameObject/enemy/`

### 新增武将（{拼音名}）

1. `SourceAssets/SpineConversion/Generals/{拼音名}/` 放入 `skeleton.json` / `skeleton.atlas.txt` / `skeleton.png`
2. Unity 导入 Spine 生成 `{拼音小写}_SkeletonData.asset` / `_Atlas.asset` / `_Material.mat`
3. 资产移至 `AssetRaw/Battle/Prefabs/Generals/{拼音名}/`
4. 创建 `{拼音名}.prefab`（首字母大写）
5. **在 `BattleAssetAddressRule.cs` 的 SpineSourceDirectories 注册新目录**
6. `general.xlsx` 新增行：PrefabAddress = `{拼音名}`、AnimationKey、PartWords
7. 确认 PartWords 每个字在 `GeneralPartGlyphMap.PartWordToIndex` 有映射
8. 确认对应 `generalParts_{index}.png` 已存在

### 新增 Boss（{拼音名}）

1. `SourceAssets/SpineConversion/Boss/{拼音名}/{子目录}/` 放入 Spine 源文件
2. 导入生成资产，移至 `AssetRaw/Battle/Prefabs/Enemies/{拼音名}/`
3. 创建 `{拼音名}.prefab`
4. **在 `BattleAssetAddressRule.cs` 注册新目录**
5. `boss.xlsx` 新增行：ResourcePath = `{拼音名}`、AnimationKey、AttackAnimation、IdleAnimation
6. 确认 Spine 动画名与配置表字段一致
7. Enabled = true 才能进入正式波次计划

### 新增地图（BattleMap{N}）

1. 创建 `AssetRaw/Battle/Prefabs/World/BattleMap{N}.prefab`
2. `map.xlsx` 新增行：ResourceAddress = `BattleMap{N}`、Grid、路径等
3. 地图背景精灵放入 `Battle/Sprites/Extracted/Map/mapBg/mapBg{N}/`

### 新增兵种（{WeaponType}Soldier）

1. 创建 `AssetRaw/Battle/Prefabs/Soldiers/{WeaponType}Soldier.prefab`
2. `unit.xlsx` 新增行：AnimationKey
3. `soldier_visual.xlsx` 新增行：锚点偏移参数
4. 序列帧放入 `Battle/Sprites/Extracted/GameObject/soldier/anim/soldier_{N}/`

### 通用检查

- Spine 源目录必须在 `BattleAssetAddressRule.SpineSourceDirectories` 注册
- `Battle/Source/Laya/` 下资源不收集，运行时资源勿放此目录
- Prefab 文件名即地址，跨目录不能重名
- 地址区分大小写，配置表地址须与文件名大小写一致
- 修改 xlsx 后须运行 `gen_code_bin_to_project.bat` 重新生成代码与 bytes
