# TEngine 配置表与美术资源规范

> 本文档基于 `Configs/GameConfig/Datas/` 下的实际 xlsx 表头与 `GameScripts/HotFix/GameProto/GameConfig/` 下 Luban 生成的 C# 类核验编写。源码以生成的 `.cs` 类为准。最后核验日期：2026-08-24。

---

## 一、总览

### 1.1 技术栈与工程位置

| 项 | 值 |
|----|----|
| 配置管线 | Luban（Excel → C# 代码 + 二进制 bytes） |
| Excel 数据源 | `TEngine/Configs/GameConfig/Datas/` |
| Luban 主配置 | `TEngine/Configs/GameConfig/luban.conf` |
| 生成脚本 | `TEngine/Configs/GameConfig/gen_code_bin_to_project.bat` |
| 生成的 C# 代码 | `UnityProject/Assets/GameScripts/HotFix/GameProto/GameConfig/`（热更程序集） |
| 生成的二进制 | `UnityProject/Assets/AssetRaw/Configs/bytes/`（YooAsset 管理，PRELOAD 标签） |
| 顶层模块 / 管理器 | `GameConfig` / `Tables` |
| 分组 | `c`（client）、`s`（server）、`e`（editor），均 default=true |

### 1.2 表索引（`__tables__.xlsx`）

共注册 22 张表。命名空间分两组：`item.TbItem`（Luban 示例表，独立命名空间）和 `battle.Tb*`（战斗系统，21 张）。

二进制文件命名规则：`{namespace短名}_tb{表名小写}.bytes`，例如 `battle_tbunit.bytes`、`item_tbitem.bytes`。

| full_name | value_type | input | index | mode | 说明 |
|-----------|------------|-------|-------|------|------|
| `item.TbItem` | Item | item.xlsx | id | map | 道具示例表 |
| `battle.TbUnit` | Unit | unit.xlsx | id | map | 小兵基础配置 |
| `battle.TbUnitLevel` | UnitLevel | unit_level.xlsx | id | map | 小兵等级倍数 |
| `battle.TbEnemy` | Enemy | enemy.xlsx | id | map | 敌人目录配置 |
| `battle.TbEnemyStats` | EnemyStats | enemystats.xlsx | id | map | 敌人运行时数值 |
| `battle.TbMap` | Map | map.xlsx | id | map | 地图配置 |
| `battle.TbWave` | Wave | wave.xlsx | — | **one** | 波次选择器（单行） |
| `battle.TbWavePlan` | WavePlan | wave_plan.xlsx | id+order | **list** | 逐波计划表 |
| `battle.TbEconomy` | Economy | economy.xlsx | — | **one** | 战斗经济（单行） |
| `battle.TbProjectile` | Projectile | projectile.xlsx | — | **one** | 弹道类型（单行） |
| `battle.TbGeneral` | General | general.xlsx | id | map | 武将配置 |
| `battle.TbBoss` | Boss | boss.xlsx | id | map | Boss 配置 |
| `battle.TbSkill` | Skill | skill.xlsx | id | map | 技能配置 |
| `battle.TbBuff` | Buff | buff.xlsx | id | map | Buff 类型配置 |
| `battle.TbWeapon` | Weapon | weapon.xlsx | id | map | 武器配置（原始） |
| `battle.TbWeaponRegistry` | WeaponRegistry | weapon_registry.xlsx | id | map | 武器符号注册表（逆向快照） |
| `battle.TbWeaponText` | WeaponText | weapon_text.xlsx | id | map | 武器名字拆字 |
| `battle.TbSoldierVisual` | SoldierVisual | soldier_visual.xlsx | animationKey | map | 兵种表现 Profile（美术锚点偏移） |
| `battle.TbDeck` | Deck | deck.xlsx | mode | map | 牌组配置 |
| `battle.TbEvent` | Event | event.xlsx | id | map | 事件名映射 |
| `battle.TbRank` | Rank | rank.xlsx | id | map | 军衔关卡配置 |
| `battle.TbResultSchema` | ResultSchema | result_schema.xlsx | id | map | 战斗结算字段说明 |

**mode 说明**：
- `map`：按 index 字段索引，`Tables.TbXxx.Get(id)`
- `one`：整表只有一行全局配置，无主键，`Tables.TbXxx.DataList[0]` 访问
- `list`：列表模式，`WavePlan` 用复合索引 `id+order`，同一 planId 下 order 连续

### 1.3 引用约定（重要变更）

**本工程已统一采用数字 ID 引用，不再使用字符串 key。** 跨表引用一律为 `int` 类型的 ID：

- `wave_plan.enemyId` → `enemy.id`（非 enemyKey）
- `wave_plan.bossId` → `boss.id`（非 bossKey）
- `general.skillId` / `boss.skillId` → `skill.id`（非 skillKey）
- `skill.effectBuffId` → `buff.id`（非 effectBuffType）
- `map.enemyId` → `enemy.id`
- `enemystats.id` = `enemy.id`（同 ID 关联，非"同名 key"）

> 旧版文档中的 `key`/`mapIndex`/`planId`/`enemyKey`/`bossKey`/`skillKey`/`effectBuffType` 等字段名已废弃。本文档字段名以生成 C# 类的 PascalCase 属性为准（Excel 中是小驼峰，生成后首字母大写）。

### 1.4 Excel 行结构

每张数据表前 4 行为表头，第 5 行起为数据：

```
第1行：##var    字段名（id, name, hp, atk...）
第2行：##type   类型（int, string, float, bool, int, list,int 等）
第3行：##group  分组（c/s/cs，留空=所有分组）
第4行：##       注释（中文说明）
第5行起：       数据
```

### 1.5 类型支持

| Excel 类型 | C# 类型 | 示例 |
|-----------|---------|------|
| `int` | `int` | `100` |
| `int?` | `int?`（可空） | 留空 |
| `long` | `long` | `5000` |
| `float` | `float` | `1.5` |
| `bool` | `bool` | `true` |
| `string` | `string` | `"张飞"` |
| `string?` | `string?` | 留空 |
| `int`（逗号分隔） | `List<int>` | `1,2,3` |
| `vector2` | `Vector2` | `0.5,1.0` |
| `vector2int` | `Vector2Int` | `3,4` |
| 自定义 Bean | C# 类 | `effectAtMs,completeAtMs` |

### 1.6 复合类型（`__beans__.xlsx`）

| bean full_name | 分隔符 | 字段 | 被引用 |
|---------------|--------|------|--------|
| `boss.Timeline` | `,` | `effectAtMs`(int) / `completeAtMs`(int) | `boss.timeline` |
| `item.ItemExchange` | `,` | `id`(int) / `num`(int) | `item.exchange_*` |

### 1.7 枚举（`__enums__.xlsx`）

| enum full_name | 项 |
|----------------|----|
| `battle.EWaveKind` | `Normal`=1, `Boss`=2 |
| `item.EQuality` | `WHITE`=1, `BLUE`=2, `PURPLE`=3, `RED`=4 |

### 1.8 代码生成流程

```bash
# 在 TEngine/Configs/GameConfig/ 下运行
gen_code_bin_to_project.bat
```

生成产物：
- `GameProto/GameConfig/{battle,item}/` → `Tables.cs`、各表 `.cs`（自动生成，勿手改）
- `AssetRaw/Configs/bytes/` → `{ns}_tb{name}.bytes`

### 1.9 运行时访问

```csharp
var tables = ConfigSystem.Instance.Tables;

// map 模式：按 ID 查询
var bossCfg = tables.TbBoss.Get(1);

// 遍历
foreach (var g in tables.TbGeneral.DataList) { }

// one 模式：单行配置
var economy = tables.TbEconomy.DataList[0];
```

> `ConfigSystem` 在 `GameProto` 程序集，使用 `ModuleSystem.GetModule<IResourceModule>()`（非 `GameModule.Resource`），在 `ProcedurePreload` 之后懒加载。

## 二、配置表逐表说明

> 字段名以生成 C# 类的 PascalCase 为准；Excel 表头为小驼峰，生成后首字母大写。`?` 表示可空。

### 2.1 unit.xlsx — 小兵基础配置（TbUnit）

mode=map，index=`id`。4 个兵种（刀/弓/枪/骑）。

| 字段 | 类型 | 说明 |
|------|------|------|
| Id | int | 主键 |
| Text | string | 显示名 |
| AnimationKey | string | 动画键（knife/bow/pike/cavalry） |
| RangeCells | float | 攻击范围（格） |
| AttackDamage | int | 攻击力 |
| AttackIntervalSeconds | float | 攻击间隔（秒） |
| DamageMode | string | 伤害模式（近战/单体/近战枪击/范围） |
| TargetPolicy | string | 选敌策略（nearest/closest_end） |
| Status | string? | 状态标记（CORE_COMPLETE） |

**引用**：`AnimationKey` → `soldier_visual.animationKey`（表现锚点）。

### 2.2 unit_level.xlsx — 小兵等级倍数（TbUnitLevel）

mode=map，index=`id`。每行代表一个等级，5 行（id=1..5）。

| 字段 | 类型 | 说明 |
|------|------|------|
| Id | int | 等级 ID（主键） |
| DamageLevelMultipliers | float | 该等级伤害倍率 |
| AttackSpeedLevelMultipliers | float | 该等级攻速倍率 |

> 旧文档提到的 `maxLevel` 字段不存在；倍率是一行一等级的单值，不是列表字段。

### 2.3 enemy.xlsx — 敌人目录（TbEnemy）

mode=map，index=`id`。7 行，id=1..4 为普通敌人，id=5..7 为技能召唤类。

| 字段 | 类型 | 说明 |
|------|------|------|
| Id | int | 主键 |
| TypeIndex | int? | 普通敌人类型索引（必须唯一；留空=技能召唤类，不进普通波次） |
| ResourceAddress | string? | YooAsset Prefab 地址（如 `Mob0`，须与 Prefab 文件名一致） |

**引用**：`ResourceAddress` → `Battle/Prefabs/Enemies/Mob{N}.prefab`。普通敌人必须在 `enemystats` 中存在同 `id`。

### 2.4 enemystats.xlsx — 敌人运行时数值（TbEnemyStats）

mode=map，index=`id`。4 行（对应普通敌人 id=1..4）。

| 字段 | 类型 | 说明 |
|------|------|------|
| Id | int | 敌人类型 ID（= enemy.id） |
| MoveSpeed | int | 移动速度（px/s） |
| HealthByWave | List<int> | 各难度索引基础血量（当前 20 个值） |
| EarlyRoundHealthMultipliers | List<float> | 前期波次血量倍率（c 组） |
| ContactDamage | int | 接触目标伤害 |
| RewardGold | int | 击杀奖励金币 |

**引用**：`HealthByWave` 被 `wave_plan.difficultyIndex` 索引（从 0 开始，长度须覆盖所有 difficultyIndex）。

### 2.5 map.xlsx — 地图配置（TbMap）

mode=map，index=`id`。4 张地图，8×10 格，格尺寸 80×80。

| 字段 | 类型 | 说明 |
|------|------|------|
| Id | int | 主键（开局选地图的唯一依据） |
| Width / Height | int | 逻辑格子数（8 / 10） |
| GridWidth / GridHeight | int | 格尺寸（80） |
| CellWidth / CellHeight | int | 像素格尺寸（80） |
| Grid | List<List<string>> | 列优先 grid[x][y]，编码 `kind_lane`（`;` 分隔外层，`,` 分隔内层） |
| PlayerPath / OpponentPath | List<Vector2Int> | 双方逻辑路径（`;` 分隔点，点内 `,` 分隔 x,y） |
| PlayerEntry / OpponentEntry | Vector2Int | 地图外/边缘入口 |
| PlayerStart/End / OpponentStart/End | Vector2Int | 实际路径起止格 |
| RouteMarkers | List<Vector2Int> | 表现路径标记（可越界，不混进逻辑路径） |
| EnemyId | int | Normal 波默认敌人类型 ID |
| Name | string | 诊断名称（c 组，不参与规则） |
| ResourceAddress | string | 地图 Prefab 地址（如 `BattleMap0`，c 组） |
| Blocks | string? | 旧阻挡点字段（已废弃，以 grid 为权威） |
| MapCount | int | 历史总地图数记录（不负责选图） |

**grid 编码**：`kind`（0=道路/1=可放置/2=阻挡）+ `lane`（0=对手方/1=玩家方）。

**引用**：`EnemyId` → `enemy.id`；`ResourceAddress` → `Battle/Prefabs/World/BattleMap{N}.prefab`。

### 2.6 wave.xlsx — 波次选择器（TbWave）

mode=**one**（单行全局配置）。

| 字段 | 类型 | 说明 |
|------|------|------|
| Id | int | （占位） |
| ActivePlanId | int | 当前启用的计划 ID（须能在 wave_plan.id 中找到，c 组） |
| SpawnStrategies | List<List<float>> | 生成策略权重表（`;` 分隔行，`,` 分隔列） |
| WaveUnitCounts | List<int> | **已废弃** |
| BossWaveNumbers | List<int> | **已废弃** |
| BossSpawnChances | List<float> | **已废弃** |
| SpawnStrategyWeights | List<int> | **已废弃** |
| SkipBoss | bool | **已废弃** |

**引用**：`ActivePlanId` → `wave_plan.id`；`SpawnStrategies` 的行索引被 `wave_plan.strategyProfile` 引用（从 0 开始）。

### 2.7 wave_plan.xlsx — 逐波计划表（TbWavePlan）

mode=**list**，复合索引 `id+order`，group=`c`。21 行（id=1，order=1..21）。

| 字段 | 类型 | 说明 |
|------|------|------|
| Id | int | 计划 ID（引用 wave.activePlanId） |
| Order | int | 波次顺序（从 1 起连续递增，不可重复/跳号） |
| Kind | EWaveKind | 波次类型（Normal=1 / Boss=2） |
| EnemyId | int? | Normal 波敌人 ID（留空时用地图的 enemyId） |
| NormalCount | int | 普通怪数量（Boss 波填 0） |
| DifficultyIndex | int | 难度索引（索引 enemystats.healthByWave，从 0 起） |
| BossId | int? | Boss 波必填（Boss 波填，Normal 波留空） |
| PreDelayMs | long | 本波开始前等待（毫秒） |
| SpawnIntervalMs | long | 普通怪出生间隔（毫秒） |
| PostDelayMs | long | 本波结束后等待（毫秒） |
| PlayerLane | bool | 玩家侧是否生成 |
| OpponentLane | bool | 对手侧是否生成（至少一侧须为 true） |
| StrategyProfile | int | 生成策略索引（引用 wave.spawnStrategies 行，从 0 起） |

**约束**：`Order` 连续递增；`Kind` 只能 Normal/Boss；Boss 波 `NormalCount`=0；至少一侧 lane 为 true。

### 2.8 economy.xlsx — 战斗经济（TbEconomy）

mode=**one**（单行）。

| 字段 | 类型 | 说明 |
|------|------|------|

### 2.13 buff.xlsx — Buff 类型配置（TbBuff）

mode=map，index=`id`。20 行。

| 字段 | 类型 | 说明 |
|------|------|------|
| Id | int | 全局唯一 Buff 数字 ID |
| Name | string | 稳定英文键 |
| Label | string? | 中文显示名（可空） |
| Kind | int | 0=Numeric / 1=State / 2=Custom |
| Channels | List<int> | 通道列表（`,` 分隔） |
| StackPolicy | string | 严格填 `Add`/`Refresh`/`Replace` |
| MaxStacks | int | 最大层数（>0） |
| ConflictKey | string? | 同冲突键的其他 Buff 会被替换；无互斥留空 |

**Channels 语义**：
- Numeric（kind=0）：0攻击、1攻速、2范围、3移速、4最大生命、5当前生命、6缩放

## 三、美术资源制作规范

### 3.1 资源根目录

```
UnityProject/Assets/
├── AssetRaw/                    ← YooAsset 管理的资源根（DefaultPackage）
│   ├── Battle/                  ← 战斗资源（核心，自定义地址规则）
│   │   ├── Prefabs/
│   │   │   ├── Enemies/         ← 普通敌人 Mob0~3 + Boss Spine 簇
│   │   │   ├── Generals/        ← 武将 Spine 簇
│   │   │   ├── Soldiers/        ← 兵种 Prefab
│   │   │   ├── Projectiles/     ← 投射物
│   │   │   ├── Targets/         ← 保护目标
│   │   │   └── World/           ← 地图 Prefab
│   │   ├── Sprites/             ← 战斗精灵/贴图
│   │   └── Source/Laya/         ← Laya 源图集（被 Filter 排除，不打包）
│   ├── Configs/                 ← Luban bytes（PRELOAD）
│   └── ...                      ← Actor/Audios/UI 等
├── SourceAssets/                ← 源美术资源
│   └── SpineConversion/         ← Spine 原始导入
│       ├── Boss/{Name}/{sub}/
│       └── Generals/{Name}/
└── Editor/AssetBundleCollector/ ← YooAsset 收集器配置
    ├── AssetBundleCollectorSetting.asset
    ├── BattleAssetAddressRule.cs
    └── BattleDerivedAssetFilter.cs
```

### 3.2 YooAsset 地址规则

**全局设置**：`EnableAddressable=true`、`LocationToLower=false`（地址区分大小写）、`SupportExtensionless=true`。

**Battle Group（自定义规则）**——`BattleAssetAddressRule.cs`：

| 资源类型 | 地址计算 | 示例 |
|---------|---------|------|
| Prefab（.prefab） | 文件名去扩展名 | `Mob0.prefab` → `Mob0`；`BattleMap0.prefab` → `BattleMap0` |
| Spine 源文件（.json/.atlas.txt/.png） | 相对 CollectPath 的完整路径（保留扩展名） | `zhangfei.json` → `Prefabs/Generals/ZhangFei/zhangfei.json` |
| 普通贴图等其余 | 相对 CollectPath 去扩展名路径 | `generalParts_0.png` → `Sprites/Extracted/GameObject/soldier/generalParts_0` |

> Spine 源目录必须在 `BattleAssetAddressRule.SpineSourceDirectories` 数组中注册，否则同名 .json/.png 地址会冲突。当前已注册：`ZhangLiang`、`ZhangFei`、`HuangZhong`。

**Battle Filter**——`BattleDerivedAssetFilter.cs`：排除 `Battle/Source/Laya/` 整个子树（只读源图集，不打包）。

**其他 Group**：Actor/Audios/Configs/Effects/UI 等用 `AddressByFileName` + `PackDirectory`（UI 为 `PackSeparately`）。Configs 带 `PRELOAD` 标签。

### 3.3 Prefab 命名规范

| 类别 | 命名模式 | 示例 | 配置表字段 |
|------|---------|------|-----------|
| 普通敌人 | `Mob{N}` | Mob0, Mob1 | `enemy.resourceAddress` |
| Boss | `{拼音名}`（首字母大写） | ZhangLiang | `boss.resourcePath` |
| 武将 | `{拼音名}`（首字母大写） | ZhangFei, HuangZhong | `general.prefabAddress` |
| 兵种 | `{WeaponType}Soldier` | SpearSoldier, BowSoldier, KnifeSoldier, CavalrySoldier | （代码直接引用） |
| 投射物 | `{Name}` | Arrow | `projectile.primaryType` 对应 |
| 保护目标 | `{角色名}` | ADou | （代码直接引用） |
| 地图 | `BattleMap{N}` | BattleMap0 | `map.resourceAddress` |

> **Prefab 文件名即 YooAsset 地址**，跨目录不能重名。地址区分大小写，配置表填写的地址必须与文件名大小写一致。

### 3.4 Spine 资源规范

## 四、美术制作 Checklist

### 4.1 新增普通敌人（Mob{N}）

1. 创建 `Assets/AssetRaw/Battle/Prefabs/Enemies/Mob{N}.prefab`（文件名即地址）
2. Luban `enemy.xlsx` 新增行：`Id` / `TypeIndex`（唯一）/ `ResourceAddress` = `Mob{N}`
3. Luban `enemystats.xlsx` 新增同 `Id` 数值行
4. 确认 `TypeIndex` 与 `EnemyFactory` 映射一致
5. 散件精灵放入 `Battle/Sprites/Extracted/GameObject/enemy/`

### 4.2 新增武将（{拼音名}）

1. `Assets/SourceAssets/SpineConversion/Generals/{拼音名}/` 放入 `skeleton.json` / `skeleton.atlas.txt` / `skeleton.png`
2. Unity 导入 Spine，生成 `{拼音小写}_SkeletonData.asset` / `_Atlas.asset` / `_Material.mat`
3. 资产移至 `Assets/AssetRaw/Battle/Prefabs/Generals/{拼音名}/`
4. 创建 `{拼音名}.prefab`（首字母大写）
5. **在 `BattleAssetAddressRule.cs` 的 `SpineSourceDirectories` 注册新目录**
6. Luban `general.xlsx` 新增行：`PrefabAddress` = `{拼音名}`、`AnimationKey`、`PartWords`
7. 确认 `PartWords` 每个字在 `GeneralPartGlyphMap.PartWordToIndex` 有映射
8. 确认对应 `generalParts_{index}.png` 已存在

### 4.3 新增 Boss（{拼音名}）

1. `Assets/SourceAssets/SpineConversion/Boss/{拼音名}/{子目录}/` 放入 Spine 源文件
2. 导入生成资产，移至 `Assets/AssetRaw/Battle/Prefabs/Enemies/{拼音名}/`
3. 创建 `{拼音名}.prefab`
4. **在 `BattleAssetAddressRule.cs` 注册新目录**
5. Luban `boss.xlsx` 新增行：`ResourcePath` = `{拼音名}`、`AnimationKey`、`AttackAnimation`、`IdleAnimation`
6. 确认 Spine 动画名与配置表字段一致
7. `Enabled` = true 才能进入正式波次计划

### 4.4 新增地图（BattleMap{N}）

1. 创建 `Assets/AssetRaw/Battle/Prefabs/World/BattleMap{N}.prefab`
2. Luban `map.xlsx` 新增行：`ResourceAddress` = `BattleMap{N}`、`Grid`、路径等
3. 地图背景精灵放入 `Battle/Sprites/Extracted/Map/mapBg/mapBg{N}/`

### 4.5 新增兵种（{WeaponType}Soldier）

1. 创建 `Assets/AssetRaw/Battle/Prefabs/Soldiers/{WeaponType}Soldier.prefab`
2. Luban `unit.xlsx` 新增行：`AnimationKey`
3. Luban `soldier_visual.xlsx` 新增行：锚点偏移参数
4. 序列帧放入 `Battle/Sprites/Extracted/GameObject/soldier/anim/soldier_{N}/`

### 4.6 新增投射物

1. 创建 `Assets/AssetRaw/Battle/Prefabs/Projectiles/{Name}.prefab`
2. Luban `projectile.xlsx` 新增类型
3. 精灵放入 `Battle/Sprites/Projectiles/{Name}/`

### 4.7 通用检查

- Spine 源目录必须在 `BattleAssetAddressRule.SpineSourceDirectories` 注册，否则同名 .json/.png 地址冲突
- `Battle/Source/Laya/` 下资源不收集（被 Filter 排除），运行时资源勿放此目录
- Prefab 文件名即地址，跨目录不能重名
- 地址区分大小写（`LocationToLower=false`），配置表地址须与文件名大小写一致
- 修改 xlsx 后须运行 `gen_code_bin_to_project.bat` 重新生成代码与 bytes
