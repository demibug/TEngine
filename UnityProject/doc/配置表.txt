unit_level.xlsx——士兵升级倍率
unit_level.xlsx (Sheet1!A1:D5)
- maxLevel：战斗允许的最大等级。
- damageLevelMultipliers：从 1 级开始的伤害倍率列表。
- attackSpeedLevelMultipliers：从 1 级开始的攻速倍率列表。
两组倍率至少要覆盖 maxLevel。当前 maxLevel=3，但表中给了 5 个倍率，后两项目前不会正常用到。
3. enemy.xlsx——敌人目录与资源绑定
enemy.xlsx (Sheet1!A1:I12)
- key：敌人唯一键，例如 Mob0。
- typeIndex：普通敌人类型索引；必须唯一。没有索引的行被视为技能召唤类，不进入普通波次目录。
- resourceAddress：YooAsset Prefab 地址，例如 Mob0，必须与 Prefab 文件名一致。
- symbol/status/resource/deferred/levelMultipliers：逆向记录和说明字段，当前主运行时不使用。
普通敌人必须在 enemystats.xlsx 中存在同名 enemyKey。
4. enemystats.xlsx——敌人数值
enemystats.xlsx (Sheet1!A1:G8)
- enemyKey：必须引用 enemy.key。
- moveSpeed：移动速度，当前语义为逻辑像素/秒。
- healthByWave：各难度索引的基础生命列表；wave_plan.difficultyIndex 会索引它。
- earlyRoundHealthMultipliers：前期波次额外血量倍率。
- contactDamage：抵达终点时造成的伤害。
- rewardGold：击杀奖励金币。
healthByWave 长度必须覆盖所有波次使用到的 difficultyIndex。
5. map.xlsx——战场逻辑地图与地图 Prefab
map.xlsx (Sheet1!A1:W9)
- mapIndex：地图主键，也是开局选择地图的唯一依据。
- width/height：逻辑格子数量，当前为 8×10。
- gridWidth/gridHeight、cellWidth/cellHeight：原始像素格尺寸，当前为 80×80。
- grid：列优先的 grid[x][y]。编码为 kind_lane：
  - 0：道路，可行走；
  - 1：可放置单位；
  - 2：阻挡；
  - lane=0 对手方，lane=1 玩家方。
- playerPath/opponentPath：双方游戏逻辑路径，点用 x,y，点之间用 ;。
- playerEntry/opponentEntry：地图外或边缘入口。
- playerStart/playerEnd、opponentStart/opponentEnd：实际路径起止格。
- routeMarkers：纯表现路径标记，可包含越界点，不应混进逻辑路径。
- enemyTypeIndex：Normal 波未填 enemyKey 时使用的默认敌人类型。
- name：诊断名称，不参与规则。
- resourceAddress：地图 Prefab 地址，例如 BattleMap0。
- blocks：旧阻挡点字段；现在以 grid 为权威。
- mapCount：历史总地图数记录，不负责选择本局地图。
6. wave.xlsx——波次计划选择器与生成策略
wave.xlsx (Sheet1!A1:H6)
- activePlanId：当前启用的计划 ID，必须能在 wave_plan.planId 中找到。
- spawnStrategies：二维权重表；wave_plan.strategyProfile 是这里的行索引。
- waveUnitCounts/bossWaveNumbers/bossSpawnChances/spawnStrategyWeights/skipBoss：旧兼容字段，不再决定有限关卡的正式波次内容。
7. wave_plan.xlsx——逐波正式配置
wave_plan.xlsx (Sheet1!A1:N25)
- planId：计划分组键，应与 wave.activePlanId 一致。
- order：从 1 开始连续递增，不可重复、不可跳号。
- kind：只能填 Normal 或 Boss。
- enemyKey：Normal 波敌人；留空时使用地图的 enemyTypeIndex。
- normalCount：Normal 波怪物数；Boss 波填 0。
- difficultyIndex：索引 enemystats.healthByWave，从 0 开始。
- bossKey：Boss 波必填，引用已启用的 boss.key。
- preDelayMs：本波开始前等待时间。
- spawnIntervalMs：普通怪之间的出生间隔。
- postDelayMs：本波结束后的等待时间。
- playerLane/opponentLane：该侧是否生成；至少一侧必须为真。
- strategyProfile：引用 wave.spawnStrategies 的从 0 开始索引。
8. economy.xlsx——战斗经济
economy.xlsx (Sheet1!A1:H6)
- initialGold：开局金币。
- refreshCostStart：首次刷新费用。
- refreshCostIncrement：每次刷新增加的费用。
- unitBaseCost：基础招募/单位费用。
- handSize：手牌数量。
- playerMaxHealth/opponentMaxHealth：设计上是双方目标生命。
注意：当前 Provider 仍把双方生命硬编码为 3/3，后两个字段现在修改不会生效。
9. buff.xlsx——Buff 类型目录
buff.xlsx (Sheet1!A1:I24)
- type：全局唯一 Buff 数字 ID；技能通过它引用。
- name：稳定英文键。
- label：中文显示名，可空。
- kind：
  - 0=Numeric 数值型；
  - 1=State 状态型；
  - 2=Custom 自定义处理器。
- channels：逗号列表。
  - Numeric：0攻击、1攻速、2范围、3移速、4最大生命、5当前生命、6缩放。
  - State：0禁移动、1禁攻击、2改变选敌、3压制、4伤害脉冲、5击退脉冲、6移动锁定。
- stackPolicy：严格填写 Add、Refresh 或 Replace。
- maxStacks：最大层数，必须大于 0。
- conflictKey：同冲突键的其他 Buff 会被替换；无互斥需求时留空。
10. skill.xlsx——技能目录与数值
skill.xlsx (Sheet1!A1:P23)
- key：全局唯一英文键，同时被武将或 Boss 引用。
- name/description：显示和策划说明；当前领域快照不用于表现。
- category：只能填小写 active、boss、passive。
- cooldownSeconds：冷却秒数，必须填写且不能为负。
- handlerKey：代码处理器注册键，不能为空；必须由程序确认已注册。
- rangeTiles：作用范围格数，只被特定 Handler 解释。
- effectBuffType：引用 buff.type。
- effectDurationMs：Buff/效果持续毫秒。
- triggerAttackCount：累计多少次普通攻击后触发主动技能。
- effectDamageMultiplier：技能伤害倍率，例如火箭每箭倍率。
- healthMultiplier/speed：逆向记录字段，当前通用技能运行时不消费。
- source/confidence：溯源与可信度说明，不参与游戏逻辑。
目前正式接通的武将技能主要是 BattleShout 和 FireArrowBarrage；表中存在并不等于 Handler 已实现。
11. boss.xlsx——Boss 逻辑、资源和动画
boss.xlsx (Sheet1!A1:S16)
- key：Boss 唯一键，被 wave_plan.bossKey 引用。
- name：显示名。
- skillKey：引用 skill.key，技能类别应为 boss。
- animationKey：Boss 表现绑定键，必填。
- resourcePath：实际是 YooAsset Prefab 地址，不是磁盘路径，例如 ZhangLiang。
- attackAnimation：Spine 普通攻击动画名。
- followupAnimation：后续攻击动画；当前 Provider 尚未消费。
- idleAnimation：Spine 待机/移动循环动画名。
- timeline.effectAtMs：技能逻辑效果提交时刻。
- timeline.completeAtMs：技能动作完成时刻；必须大于 effectAtMs。
- enabled：只有启用 Boss 才允许进入正式计划。
- healthMultiplier：Boss 基础生命倍率。
- moveSpeed：移动速度。
- contactDamage：到达终点伤害。
- rewardGold：击杀金币。
- logicalWidth/logicalHeight：逻辑尺寸，用于中心、范围及表现定位。
- originalSymbol/sourceRange：逆向溯源字段，当前逻辑不使用。
当前只有 ZhangLiang 具备正式资源并启用。
12. general.xlsx——武将配方、战斗和 Spine 绑定
general.xlsx (Sheet1!A1:T16)
- index：武将唯一 ID。
- name：完整名称。
- family：姓氏字。
- partWords：严格两个不同的字，按顺序构成合成配方，例如 张,飞。
- enabled：只有启用行进入配方、招募池和战斗目录。
- combatArchetype：当前只支持小写 pike 或 bow。
- rangeCells/attackDamage/attackIntervalSeconds：范围、一级伤害、攻击间隔，均必须为正。
- damageMode/targetPolicy：沿用士兵原型的模式，目前建议 近战枪击+nearest 或 单体+nearest。
- prefabAddress：武将 Prefab 地址，例如 ZhangFei。
- animationKey：实际传给 Spine 的待机动画名；当前为 zhan1。
- projectileType/projectileSpeed：弓型武将必填；枪型武将必须留空且速度为 0。
- partRecruitWeight：两个配方字进入招募池的权重，必须大于 0。
- skillKey：主动技能引用。
- weaponType/status：当前主要是说明和逆向记录，领域配置未使用。
当前启用的是张飞和黄忠。
13. weapon.xlsx——武器目录
weapon.xlsx (Sheet1!A1:N48)
- id：唯一 ID。
- type：0弓、1枪、2刀、3剑。
- addAttPower：增加攻击力。
- enabled：是否正式接入。
- handlerKey：启用武器必填，当前基础武器为 Basic。
- txt/rarity/rareTxt/exclusive/scale/anchorY/intro/fragmentNum：名称、稀有度、美术缩放、锚点、描述和碎片数据；目前武器战斗目录不消费这些字段。
现状要求恰好四把基础武器启用，分别覆盖四种 type。
